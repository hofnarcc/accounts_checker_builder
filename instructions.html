Installation and Prerequisites

Before using the HOFNAR05 Universal Account Checker, ensure that your system meets the following requirements:

  • Python 3.11.8
  • Google Chrome installed at C:\Program Files\Google\Chrome\Application\chrome.exe
  • Stable internet connection

The script will automatically check and install the necessary Python packages. However, ensure that you have administrative privileges to allow package installations and updates.

Detailed Function Explanations

1. Pip Upgrade and Package Installation

  • update_pip():

    Upgrades pip to the latest version using subprocess. Ensures that all package installations and upgrades proceed smoothly.

  • install_or_upgrade_package(package_name):

    Attempts to install a specified Python package. If the installation fails, it tries to upgrade the package. Provides console feedback using colored messages.

  • check_and_install_packages(package_list):

    Iterates through a list of required packages, checking if each is installed. If a package is missing, it installs or upgrades it using the aforementioned functions.

2. Python Version Check

  • check_python_version():

    Verifies that Python version 3.11.8 is installed. If not, it displays an error message via a GUI messagebox and exits the program.

3. Database Management

  • setup_database(db_name):

    Initializes an SQLite database with the specified name. Creates a table named accounts if it doesn't already exist, designed to store account email, password, and a checked status.

  • account_already_checked(account, db_name):

    Checks if a given account (email and password) has already been verified within the database to avoid redundant processing.

  • mark_account_checked(email, password, db_name):

    Updates the database to mark an account as checked, preventing it from being processed again.

4. Browser Functions

  • load_chrome_extensions(options):

    Loads Chrome extensions from the chrome_extensions folder into the browser session. Useful for adding functionalities or bypassing certain web restrictions.

  • open_undetected_browser_with_options(...):

    Launches an undetected Chrome browser instance with customizable options such as incognito mode, headless mode, user agents, and additional Chromedriver arguments. Integrates webdriver-manager for automatic Chromedriver management.

  • close_browser_instance():

    Safely closes the currently active browser instance to free system resources and ensure clean termination of browser sessions.

5. Account Checking Functions

  • check_account(...):

    Performs the primary function of verifying an individual account. It navigates to the target website, inputs the provided email and password, handles potential CAPTCHA challenges, and determines the validity of the account based on URL redirections and HTML content.

  • check_accounts_logic(...):

    Processes a list of accounts by iterating through each one, managing proxies, initiating browser sessions, and invoking check_account() for verification. Handles user agent rotation and integrates invalid account and CAPTCHA handling settings.

  • run_account_checks(...):

    Executes the account checking process in a separate thread to maintain the responsiveness of the GUI. Provides user feedback upon completion or in case of errors.

  • save_valid_account(...):

    Saves valid account details, including additional information like username and balance, to designated files. Takes screenshots of successful sessions for documentation and auditing purposes.

6. GUI Functions

  • gui_check_accounts():

    Handles the "Check Accounts" button click event. It gathers all user inputs from the GUI, validates them, parses the account list, and initiates the account checking process by starting a new thread.

  • import_proxies_from_file():

    Allows users to import a list of proxies from a selected text file. Supports proxies with or without authentication and stores them for use during account checking.

  • select_user_agents_file():

    Enables users to select a custom user agents file, which the script will use to rotate user agents, enhancing stealth and reducing the chance of detection.

  • create_config(), import_config(), export_config(), save_config_state(), load_config_data(), save_config_data(), reset_to_default():

    Manage configuration settings through the GUI. Users can create new configurations, import existing ones, export current settings, save the state, load configurations, and reset all parameters to their default values.

7. Utility Functions

  • CreateToolTip(object):

    Class that creates tooltips for various GUI widgets, providing users with contextual information and guidance.

  • print_action(message), print_checkpoint(delay), countdown_sleep(seconds):

    Utility functions that handle colored console outputs and sleep durations with countdowns. Enhance user feedback and control over script execution pacing.

8. Chromedriver Arguments Management

  • add_chromedriver_argument(), remove_chromedriver_argument():

    Allow users to add or remove custom Chromedriver command-line arguments through the GUI. Provides flexibility to modify browser behavior as needed.

9. Mouse Click Automation

  • add_mouse_click_action_extended(), remove_mouse_click_action_extended(frame):

    Enable users to define specific mouse click actions by specifying coordinates, the number of clicks, and intervals. Automates interactions with web elements that require mouse actions.

10. Pause/Resume and Force Stop

  • pause_resume():

    Toggles the pause and resume state of the account checking process. Allows users to temporarily halt execution without terminating the entire script.

  • force_stop():

    Provides a means to immediately stop the account checking process. Safely terminates browser instances and resets control flags.

11. Profile Selection

  • select_profile():

    Facilitates the selection of a specific Chrome profile to be used during browser automation. Ensures that the correct user data and settings are applied during account verification.

Using the GUI

The HOFNAR05 Universal Account Checker features a user-friendly GUI organized into multiple tabs, each dedicated to specific settings and functionalities. Below is a guide on how to navigate and utilize each section:

1. General Settings

Configure the essential parameters required for account checking:

  • Website Target Link: The URL of the website where account verification will be performed.
  • Website Valid Link: The URL breakpoint indicating a successful login.
  • Redirect URL: Optional URL to handle specific redirections during login.
  • CSS Selector for Email / Username: The CSS selector targeting the email or username input field.
  • Sleep Duration for Email Field: Time in seconds the script waits before interacting with the email field.
  • CSS Selector for Password: The CSS selector targeting the password input field.
  • Sleep Duration for Password Field: Time in seconds the script waits before interacting with the password field.
  • CSS Selector for Submit / Login Button: The CSS selector targeting the submit or login button.
  • Sleep Duration for Submit Button: Time in seconds the script waits before clicking the submit button.
  • CSS Selector for Next Button: Optional CSS selector for websites with a multi-step login process.
  • CSS Selector for Username: Optional CSS selector to capture the username from the validated account.
  • CSS Selector for Balance: Optional CSS selector to capture the account balance.
  • Speed %: Determines the pacing of the script's actions, affecting delays and timeouts.
  • 2FA Valid Link: Optional URL pattern to handle accounts requiring two-factor authentication.

2. Invalid Account Implementation

Set up the criteria for identifying invalid accounts:

  • Enable Invalid Account Checks: Toggle to activate invalid account detection.
  • Redirect Detection URL: URL that indicates an account has been redirected due to invalid credentials.
  • Error/Alert Detection CSS Selector: CSS selector targeting error messages or alerts on the webpage.
  • Inner HTML Text: Specific text within the HTML that signifies an invalid account.
  • Outer HTML Text: Specific outer HTML content that signifies an invalid account.

3. CAPTCHA Incorrect Implementation

Configure how the script handles incorrect CAPTCHA entries:

  • Enable CAPTCHA Incorrect Checks: Toggle to activate CAPTCHA handling.
  • Redirect Detection URL: URL indicating a CAPTCHA failure and prompting a recheck.
  • Error/Alert Detection CSS Selector: CSS selector targeting CAPTCHA error messages.
  • Inner HTML Text: Specific text within the HTML that signifies a CAPTCHA failure.
  • Outer HTML Text: Specific outer HTML content that signifies a CAPTCHA failure.

4. Proxy Settings

Manage proxy configurations to mask your IP and avoid detection:

  • Enable Proxy: Toggle to activate proxy usage.
  • Proxy Type: Select the type of proxy (HTTP, HTTPS, SOCKS5).
  • Proxy Mode: Choose between Static Proxies (same proxy for all accounts) or Rotating Proxies (different proxies for each account).
  • Import Proxies from File: Load a list of proxies from a text file into the application.

5. Browser Settings

Customize browser behavior for optimal performance and privacy:

  • Clean Browser Data After Each Account: Toggle to clear cookies, cache, and local storage after each account check.
  • Run Browser in Incognito Mode: Toggle to start the browser in incognito mode for enhanced privacy.

6. Advanced Settings

Access additional configurations for more control over the browsing session:

  • Load Chrome Extensions: Toggle to load extensions from the chrome_extensions folder.
  • Disable Browser Notifications: Prevent pop-up notifications from appearing during the session.
  • Disable Infobars: Remove informational bars from the browser interface.
  • Start Browser Maximized: Configure the browser window to open in maximized mode.
  • Disable Browser Extensions: Disable all browser extensions to prevent interference.
  • Run Browser in Headless Mode: Execute the browser without a visible UI for better performance.
  • Use Custom User Agents: Toggle to use custom user agents loaded from a specified file.
  • Select User Agents File: Load a text file containing custom user agents for rotation.

7. Chromedriver Arguments Management

Add or remove specific Chromedriver command-line arguments to modify browser behavior:

  • Add Chromedriver Argument: Input a command-line argument (e.g., --disable-gpu) and add it to the list.
  • Remove Selected Argument(s): Select and remove previously added Chromedriver arguments from the list.
  • Chromedriver Arguments List: View all currently active Chromedriver arguments.
  • Find Chromium Command-Line Switches: Provides a link to reference additional Chromium command-line switches.

8. Mouse Click Automation

Automate mouse clicks at specific screen coordinates to interact with dynamic webpage elements:

  • Enable Mouse Click Automation: Toggle to activate mouse click actions during account checks.
  • Add Click Action: Define a new mouse click action by specifying the X and Y coordinates, number of clicks, and interval between clicks.
  • Remove Click Action: Delete a previously defined mouse click action.

9. Pause/Resume and Force Stop

  • Pause/Resume Button: Click to pause the ongoing account checking process or resume it if paused.
  • Force Stop Button: Immediately terminate all account checking operations and close browser instances.

10. Profile Selection

Select the Chrome profile to be used during browser automation:

  • Select Chrome Profile: Choose from available Chrome profiles to ensure the correct user data is applied during account verification.
